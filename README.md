# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 到货抽检闸门

- 顶栏分「IV 扫描录入」与「抽检名册」两页。名册三列：左列待抽检、中列已抽检（已作废批次灰显带标记）、右列绑定样例；尚无任何绑定记录时右列显示「还没有抽检记录」。
- **组串没有完成到货抽检就不能入队**：提交扫描必须选择已抽检批次；漏选、选到待抽检或已作废批次、批次未绑定该组串，服务端整笔退回（400），不落库。仅隐藏前端按钮或绕接口改写 batch_id 同样被挡。
- 批次绑上单据后，批次号快照写入 `iv_scans.batch_no`；批次日后作废，旧单仍印原批次号，只是新提交被拒。
- 观察员（watcher）可翻阅名册，但抽检、作废、绑定、提交等一切写入均为 403。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`
