# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 到货抽检闸门

**组串没有完成到货抽检就不能入队。**

- 顶栏「抽检名册」专页三列：左列**待抽检**、中列**已抽检**（可绑定组串/作废）、右列**绑定样例**；空列显示「还没有抽检记录」。
- 录入扫描必须点选**已抽检且已绑定本组串**的批次：漏点、点到待抽检、点到已作废批次，整笔退回、不入队。
- 批次绑上单据的瞬间，批次号冻进单据行（`iv_scans.batch_no` 快照）；批次之后作废，旧单据仍印着原批次号，不回写、不替换；作废后再送一律被挡。
- 闸门同时在应用层和数据库触发器（`trg_iv_scan_gate`）各做一遍：只藏网页按钮、直写写入通道、或在写入数据里偷换批次号，都过不了。
- 观察员（watcher）能翻名册和单据，但登记/抽检/绑定/作废/提交全部 403。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`
